# lighter-princess
While watching Lighter & Princess, there was a scene that quietly stayed with me. In Episode 5, a professor asks students to create a heart using Python. The protagonist turns simple equations into a beautiful animated heart, and I remember pausing the episode thinking, “How does code create something that feels emotional?”

That curiosity stayed in my mind long after the episode ended.

So I started researching parametric equations, particle systems, and animation logic in Python. What began as recreating a scene slowly became an exploration of how math, motion, and emotion can exist together through code.

I built a glowing particle-based heart animation using Python, where thousands of particles follow mathematical curves to form a living, breathing heart. Beyond the visual itself, this project became a reminder that inspiration can come from anywhere — even a single scene in a drama.
